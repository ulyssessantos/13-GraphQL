# Canal Conciliar - Fluxo "Sou advogado"

Este repositório reúne a pré-visualização estática e o projeto Angular/PrimeNG que simulam o fluxo para advogados do portal Canal Conciliar.

Todo o código está organizado em `ulyssessantos/canalconciliar-advogado` para refletir a estrutura solicitada.

Consulte `ulyssessantos/canalconciliar-advogado/README.md` para detalhes de instalação, execução e visualização rápida.
